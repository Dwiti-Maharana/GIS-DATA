Layer details

Find a layer on ArcGIS Online

Search results appear here. Only public Feature and Map layers are shown — private or Esri-only layers won’t work with this tool.

How to use

  1. Paste the layer address (it ends in /FeatureServer/0 or /MapServer/3) and press Add to map. A service address without a number adds all of its layers — useful for a service that bundles, say, parcel polygons and parcel points together. You don't have to hunt down the raw address either: pasting an ArcGIS app link (a Map Viewer “Add layer from URL” link, a Field Maps/Experience Builder/StoryMaps link, anything with ?url=… in it) or a portal item page link (arcgis.com/home/item.html?id=…) works too — the tool finds the real service address inside it automatically. Don't have any address? Press Find layer… next to the bar to search ArcGIS Online by place or topic (e.g. “parcels Nodaway County”) and add a result with one click — only public Feature/Map layers are shown, since that's the only kind this tool can read.
  2. Use Go to place on the ribbon to jump the map to any address, city, state, or country — or paste raw coordinates like 41.85, -87.65 (lat, lon) to jump straight there. Powered by OpenStreetMap's free search, so results are place names and addresses, not parcel data.
  3. Big layers such as county parcels only draw once you zoom in (the minimum zoom is shown on the layer card). Zoom in, then click any shape: its attributes appear in the Attributes pane on the right (Shift/Ctrl-click to select several).
  4. Use Definition query on the layer card to filter, for example municipality = 'OAK PARK'. The Attribute table lists what is loaded in the current view.
  5. Press Download. Choose the file format (Shapefile, KML, KMZ or GeoJSON), then the map view, a box you drew, or the entire layer, then press Download. Tick “Download every matching feature” to remove the size limit entirely and fetch everything that matches, however many features that is — for a county-wide parcel layer this can be a large file and take a while, since ArcGIS servers only return a few thousand features per request.
  6. Editable layers (draw your own parcels, lines and points): press New layer to choose Polygon, Line or Point and set its attribute fields, or just pick a tool in Draw and a layer is created for you. Polygon/Line: click each corner, then double-click (or press Enter) to finish; corners snap to nearby ones. Point: click once. Tick “Ask for fields after drawing” to fill in the attributes straight away.
  7. Measure: in the Measure group choose Distance (length, azimuth and bearing of every segment), Area (area and perimeter), Radius (radius, diameter, circumference, area), Coordinates (decimal degrees, DMS, UTM, Web Mercator) or Selected (totals and per-feature area, perimeter or length of the selected features). Click points on the map; double-click or Enter finishes, Backspace removes the last point, Esc clears. Pick your length and area units (feet, meters, miles, acres, hectares, guntas, cents, gaj and more) in the panel; every unit is also listed. Copy results puts the numbers on the clipboard and Save as feature… adds the shape to an editable layer.
  8. Copy & paste: select features, then press Ctrl+C (or the Copy button). Ctrl+V pastes into the active editable layer of the same type (a new layer is made if there is none). Ctrl+Shift+V (or Paste to…) lets you choose an existing layer or a new one. Online layers can be copied too, then edited once pasted.
  9. Select & edit: Select clicks a feature (Shift adds) or drags a box; Move drags features; Vertices lets you drag a feature’s dots, drag a pale middle dot to add a corner, and right-click a dot to delete it; Attributes jumps to the Attributes pane on the right, which edits one feature or all selected features at once (pick “All N features” in its list; fields showing ‹multiple values› differ, and only fields you change are updated); Delete, Undo (Ctrl+Z) and Redo (Ctrl+Y) work as you’d expect. In the attribute table, click a row to select it and double-click a cell to edit it. Edit fields adds, renames or removes attribute fields. Area, length and coordinates are filled in automatically.
  10. Rename a layer with the Rename button on its card in Contents (or double-click its name). Hand-drawn layers are auto-saved in this browser and come back when you reopen the page; use Download drawn (all features, or just the selected ones) to keep a real file.
  11. Street View: press Street View on the ribbon, then click a road on the map. The screen splits and Google Street View opens on the right, with a Google-style blue dot and view cone on the map showing where you are and which way you face. Drag that dot along the road to move Street View with it (it snaps to the nearest road), or click elsewhere to jump, drag the grey bar between the two halves to resize, and press ✕ to close. Paste a Google Maps API key (Maps JavaScript API) into the ribbon box for the full interactive view where the marker follows you as you move along the road; without a key a basic embedded view is used. The key is kept only in this browser.
  12. Import file: press Import file in the Import group (or drag files onto the map) to load a Shapefile (a .zip, or select the .shp + .dbf + .prj together), KML, KMZ, GeoJSON / Esri JSON, GPX, CSV/TSV with latitude/longitude columns or a WKT column, or a .wkt file. Several files can be picked at once. Projected shapefiles are converted to lat/lon using their .prj. Each import becomes an editable layer (separate layers for polygons, lines and points when a file mixes them), so you can edit it and download it again in any format. File Geodatabases (.gdb), GeoPackage, DWG/DXF are not supported – convert them to Shapefile or GeoJSON first.
  13. Download several layers at once: open any Download dialog and tick more layers under “Also download these layers”. They are saved together in one .zip (all files together in a single folder, no sub-folders per layer). Hand-drawn and imported layers are saved in full; service layers use the area you choose, falling back to the current map view if nothing is traced or selected on them.
  14. Shapefiles come as a .zip. Unzip it before opening in ArcGIS or QGIS. Shapefile field names are cut to 10 characters, so a _field_names.txt file lists the original names.
  15. Some servers (for example gis.cookcountyil.gov/traditional/…) refuse browser requests because they send no CORS header, even though the address opens fine in a tab. Leave Connection on Auto and the layer is retried through a public proxy; a notice appears when that happens. Public proxies are rate limited, so for a big download use your own proxy address in the box next to it, with {url} where the target address goes.

Everything runs in your browser. Nothing is uploaded anywhere except the requests sent to the ArcGIS server you entered.
